# MWM Hmi Manual

## 📖 Documentation

[MWM documentation](https://hm-info.github.io/mwm_info/)

[TT / MSC → MWM barkod bilgi sayfası (Türkçe)](https://hm-info.github.io/mwm_info/barcode-tr.html)

MWM_V3 kaynak akışına göre barkod alanları, profil / conta / renk reçete eşleşmesi, ölçü ölçeklemesi ve otomatik iş listesi eşleştirmesi. Mevcut KD658 iş dosyası rehberleri Türkçe ve İngilizce olarak korunur.

Kaynak Markdown dosyaları `docs/` altındadır. Yerel kontrol: `pip install -r requirements.txt` ardından `mkdocs build --strict`. `main` dalına gönderim mevcut iş akışıyla GitHub Pages yayını oluşturur.
